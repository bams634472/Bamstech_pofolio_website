04
School Management System
A full-stack school ERP prototype built from a formal design document, implementing the foundational layer that every other module depends on — fully working end-to-end from database to API to UI. Stack: Next.js (React, TypeScript, Tailwind, React Query) frontend, Ruby on Rails API backend, PostgreSQL for storage, Redis for caching, all containerized with Docker. The full design spec calls for a 19-module ERP (admissions, academics, finance, attendance, exams, library, hostel, transport, CBT, payroll, communication, inventory, medical, visitor management, alumni) across 11 user roles — realistically a multi-quarter build for a full team. This prototype delivers the core foundation as production-ready functionality: Auth & RBAC — JWT authentication with full role/permission-based access control Student & Staff management — full CRUD, search, pagination; staff creation links user + staff records Academics — sessions, terms, classes, arms, and subjects Attendance — bulk daily marking by class/arm Exams & Results — score entry, weighted computation, grading, class ranking, report cards Finance — invoice creation, payment recording, automatic status updates Dashboard — live stats pulled directly from the database Audit logging — every write action tracked
Next.js (React, TypeScript, Tailwind, React Query) Ruby on Rails API PostgreSQL JavaScript Redis dockerized
